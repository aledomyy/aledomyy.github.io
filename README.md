# aledomyy.github.io

Portfolio site of Alejandro Domínguez, served with GitHub Pages at https://aledomyy.github.io.

- `index.html`: the site
- `assets/`: PDFs, images and the simulator demo video
- `code/nl-fiscal-simulator/`: R/Shiny simulator of Nuevo León's revenue-sharing formula
- `code/mananeras-text-analysis/`: scraper and text analysis of the presidential press conferences
